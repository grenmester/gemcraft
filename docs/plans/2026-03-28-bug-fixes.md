# Bug Fixes Plan

## Issues Identified

### 1. Viewport/CSS - Mobile defaulting
**Root cause:** Missing global styles and improper flex container setup
**Fix:**
- Add proper body/html height reset
- Ensure main content fills viewport properly
- Remove conflicting mobile constraints

### 2. Inventory State Persistence
**Root cause:** `DEBUG_ADD_GEM` adds to `player.gems` but Inventory reads from `player.inventory.gems`
**Fix:**
- Change `DEBUG_ADD_GEM` to use `ADD_TO_INVENTORY` with category 'gems'
- OR add new action `COLLECT_LOOT` that adds gems to inventory properly

### 3. RewardsSelector Navigation Bug
**Root cause:** Lines 48-49 dispatch `SELECT_AREA` null then back, clearing `lastRewards`
**Fix:**
- Remove the `dispatch({ type: SELECT_AREA, payload: null })` 
- Just dispatch `SET_REWARDS` and let App.jsx routing show `RewardsSummary`

### Task 2: Fix DEBUG_ADD_GEM to use Inventory
**Files:** `src/context/GameContext.jsx`

Change `DEBUG_ADD_GEM` to dispatch `ADD_TO_INVENTORY`:
```javascript
case DEBUG_ADD_GEM: {
  const gem = action.payload instanceof Gem ? action.payload : new Gem(action.payload);
  const newGemdex = state.player.gemdex.some(g => g.id === gem.id)
    ? state.player.gemdex
    : [...state.player.gemdex, gem];
  
  // Add to inventory using ADD_TO_INVENTORY pattern
  return {
    ...state,
    player: {
      ...state.player,
      gemdex: newGemdex,
      inventory: {
        ...state.player.inventory,
        gems: [
          ...(state.player.inventory?.gems || []),
          { gemId: gem.id, quantity: 1 }
        ]
      }
    }
  };
}
```
